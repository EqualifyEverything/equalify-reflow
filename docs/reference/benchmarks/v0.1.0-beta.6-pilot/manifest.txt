# Deliverable 3 pilot corpus — 30 diverse UIC documents

# Tested against Equalify Reflow v0.1.0-beta.6. The corpus was curated for
# diversity across page counts (1–20), content types (academic, policy,
# event, infographic, syllabus, newsletter, presentation), and layout
# complexity (single- vs. multi-column, scanned vs. born-digital, text- vs.
# image-heavy).
#
# PDFs are NOT checked into the repo — several are third-party copyrighted
# works. To reproduce this run, drop the source files under a `samples/`
# directory beside this manifest (paths below are relative to this file),
# or replace with your own corpus and keep the same layout.
#
# Usage:
#     uv run scripts/batch_run.py \
#         --manifest docs/reference/benchmarks/v0.1.0-beta.6-pilot/manifest.txt
#
