# Poster Layout

This page is a poster or flyer with text embedded in visual designs. Docling was unable to extract the text, so the markdown is mostly image references.

## Poster-specific guidance

- **Visual hierarchy**: Poster titles are usually the largest, most prominent text. Section headings are smaller but still visually distinct from body text.
- **Multi-region content**: Posters often have distinct content regions (panels, columns, or sections separated by visual dividers). Compose each region as its own section.
- **Event details**: Common poster elements include: event name, date, time, location, organizer, speaker names, topic descriptions, contact info, logos. Capture all of these.
- **Decorative elements**: Background images, borders, and purely decorative graphics should not be described unless they contain informational content.
- **Text in stylized fonts**: Poster text may use decorative fonts that are harder to read. Take extra care with character accuracy.

## Artifact dictionary

- **Text baked into images**: The primary challenge — significant text content appears only in the page image, not the markdown.
- **Reading order ambiguity**: Posters don't follow linear top-to-bottom flow. Use visual hierarchy and spatial grouping to determine reading order.
- **Logo text**: Organization or sponsor logos may contain text (university names, company names). Include these only if they are informational (e.g., event organizer).
