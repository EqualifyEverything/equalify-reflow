# Presentation / Slide Layout

This page has a slide-like or poster layout with text boxes rather than flowing paragraphs.

- Text is organized in discrete boxes, not a continuous linear flow.
- Reading order is less predictable -- Docling may serialize text boxes in an unexpected order compared to the visual layout.
- Title/subtitle hierarchy is conveyed by font size and position rather than numbered sections.

## Artifact dictionary

- **Reading order ambiguity**: Docling may serialize text boxes in a different order than a human would read them. Verify the content of each text region matches, even if the ordering differs.
- **Bullet points from different boxes merged**: Bullets from separate text regions may be concatenated into a single list. Check that each bullet's content matches one text region in the image.
- **Title/subtitle hierarchy**: Large prominent text is typically the slide title (heading level based on structure analysis), with smaller text as body content. Verify text accuracy of titles.
